# MONO — Telegram-плеер

Чёрно-белый минималистичный музыкальный бот: поиск, избранное, плейлисты.
Все экраны — сгенерированные картинки-карточки с инлайн-кнопками, у каждого трека своя сгенерированная обложка.

## Запуск (Windows)

1. Установите [Python 3.10+](https://www.python.org/downloads/) (галочка «Add to PATH»).
2. Создайте бота у [@BotFather](https://t.me/BotFather) → `/newbot` → скопируйте токен.
3. Скопируйте `.env.example` в `.env` и впишите токен в `BOT_TOKEN=`.
4. Запустите `start.bat` — он сам создаст окружение, поставит зависимости и запустит бота.

Вручную:

```bash
pip install -r requirements.txt
python bot.py
```

## Как пользоваться

- `/start` — главное меню.
- Любое текстовое сообщение — поиск. Нажмите номер трека, чтобы получить его.
- Под треком: `◁ ▷` — предыдущий/следующий в очереди, `☆/★` — избранное, `＋` — добавить в плейлист.
- Меню → Плейлисты → «＋ Новый плейлист».

## Мини-приложение

Плеер внутри Telegram: поиск, альбомы, избранное, плейлисты, визуализатор и 7-полосный эквалайзер с пресетами.

Telegram открывает мини-приложения только по публичному HTTPS-адресу, поэтому:

1. Бот должен работать на сервере, порт `WEBAPP_PORT` (по умолчанию 8080) должен быть доступен снаружи по HTTPS —
   через домен хостинга, обратный прокси (nginx, Caddy) или туннель (например, `cloudflared tunnel --url http://localhost:8080`).
2. Впишите этот адрес в `.env`: `WEBAPP_URL=https://ваш-адрес`.
3. Перезапустите бота. В меню появится кнопка «▷ Открыть плеер», а рядом с полем ввода — кнопка «Плеер».

Пока `WEBAPP_URL` пуст, веб-сервер не запускается и бот работает как раньше.
Для мини-приложения ffmpeg фактически обязателен: браузеру (особенно на iPhone) нужен mp3.
Скачанные треки лежат в папке `cache` (последние 100).

## Свои треки и FLAC

Пришлите боту аудиофайл (mp3, FLAC, m4a, ogg, wav) — он появится в «Лайках».
В чате работает файл любого размера; в мини-приложении — до 20 МБ (ограничение Telegram Bot API).
Если площадка-источник отдаёт трек без потерь (FLAC), он не перекодируется в mp3.

## Подписчики исполнителя на площадках

Deezer, SoundCloud и Яндекс Музыка подключаются сами. Для Spotify нужны ключи:
developer.spotify.com → Dashboard → Create app, затем переменные `SPOTIFY_CLIENT_ID` и `SPOTIFY_CLIENT_SECRET`.

## Статус в Discord

Discord может показывать в профиле, какой трек играет в мини-приложении, и сколько прошло.
Сервер бота в Discord не ходит: статус ставит маленькая программа-компаньон `discord-companion`
(лежит отдельно от репозитория: если положить .js-файл сюда, Bothost примет бота за Node.js),
которая работает на том же компьютере, что и Discord. Нужен Node.js 18+ (nodejs.org).

1. На https://discord.com/developers/applications нажмите «New Application» и назовите его `MusicCloud` —
   это название будет в строке «Слушает MusicCloud». Скопируйте «Application ID».
   По желанию: в разделе «Rich Presence → Art Assets» загрузите картинку с именем `logo` —
   она покажется, если у трека нет обложки.
2. В мини-приложении откройте Профиль → Discord и скопируйте код.
3. Запустите `discord-companion/start.bat` и вставьте код и Application ID. Они сохранятся в `config.json` рядом.

Пока окно программы открыто, статус обновляется сам; при паузе он убирается.
`config.json` — личный: с ним можно видеть, что вы слушаете. Он не попадает в Git.

## Настройки

| Что | Где |
|---|---|
| Источник поиска (`scsearch` — SoundCloud, `ytsearch` — YouTube) | `SEARCH_SOURCE` в `.env` |
| Треков на странице, лимит плейлистов | `config.py` |
| Свои шрифты | `assets/regular.ttf`, `assets/bold.ttf` |
| Цвета и вид карточек | `images.py` |

Рекомендуется установить [ffmpeg](https://ffmpeg.org/download.html) (должен быть в PATH): тогда все треки
конвертируются в mp3. Без него бот берёт только готовые mp3/m4a-потоки, и часть треков может не загрузиться.

## Файлы

- `bot.py` — обработчики и запуск
- `keyboards.py` — кнопки
- `images.py` — генерация карточек и обложек
- `music.py` — поиск и загрузка (yt-dlp)
- `webapp.py` — веб-сервер мини-приложения (API и раздача аудио)
- `webapp/index.html` — интерфейс мини-приложения
- `db.py` — SQLite: треки, избранное, плейлисты (файл `mono.db` создаётся сам)

Загружайте только ту музыку, на распространение которой у вас есть права.
